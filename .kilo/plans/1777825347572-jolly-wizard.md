# 背包 UI 优化计划

参考 `gemini-code-1777825827566.html` 设计风格，整体翻新背包模态窗口的视觉。

## 原则
- CSS 全面重写（卡片、属性面板、宝珠区、按钮、头部/底部栏）
- JS 的 **核心业务逻辑不动**（embedOrb、removeOrb、批量、排序、虚拟滚动引擎等）
- JS 的 **DOM 生成代码需要配合 CSS 调整**（改 class 名、DOM 结构、布局容器）

---

## 1. `index.html` — 模态 HTML 结构调整

当前结构 → 目标结构：

```html
<!-- 当前 -->
<div id="modal-overlay">
  <div class="modal">
    <div class="panel-title"><span id="modal-title">...</span><button id="btn-sort-backpack">...</button></div>
    <div class="modal-body">
      <div id="modal-content-area" class="inv-grid"></div>
      <div id="item-details" class="details-box">...</div>
    </div>
    <div class="modal-foot" id="modal-foot-bar">...</div>
  </div>
</div>

<!-- 目标 -->
<div id="modal-overlay">
  <div class="modal">
    <div class="terminal-header">
      <span id="modal-title">🎒 星盘背包</span>
      <button id="btn-sort-backpack" class="btn">默认顺序</button>
    </div>
    <div id="modal-content-area" class="scroll-area"></div>
    <div id="item-details" class="detail-panel" style="display:none">
      <div id="det-name"></div>
      <div id="det-stats"></div>
      <div id="det-actions"></div>
    </div>
    <div class="terminal-footer" id="modal-foot-bar"></div>
  </div>
</div>
```

**要点**：
- `#modal-content-area` class 从 `inv-grid` 改为 `scroll-area`
- `#item-details` class 从 `details-box` 改为 `detail-panel`
- `#modal-foot-bar` class 从 `modal-foot` 改为 `terminal-footer`
- 顶部标题栏从 `.panel-title` 改为 `.terminal-header`
- **所有 id 保持不变**，JS 通过 id 查找的代码无需改动

## 5. `js/ui.js` — DOM 生成配合调整

### `_renderBackpack()`（约第 396 行）

**改动**：
1. 虚拟滚动列数改为固定 `columns: 4`（原为动态计算）
2. 卡片 DOM 重构：

```js
// 旧结构
div.className = 'inv-item';
inner > nameDiv (直接文本) + scoreDiv

// 新结构
div.className = 'eq-card';
const nameDiv = document.createElement('div');
nameDiv.className = 'name ' + GEAR_RARITY[gear.rarityIdx].color;
nameDiv.textContent = label;   // 名称+强化等级+锁图标

const scoreDiv = document.createElement('div');
scoreDiv.className = 'score';
scoreDiv.textContent = `总评分: ${formatNumber(gear.score)} | ${SLOT_NAMES[gear.slot]}`;
div.append(nameDiv, scoreDiv);
```

3. 批量模式 checkbox 不再动态插入到卡片前，改为卡片内部 flex row 布局：checkbox 在左、内容在右
4. 已装备/已锁定装备在批量模式下 opacity 0.5 保持不变
5. 「显示全部装备」按钮插入位置用新选择器

### `openGearDetail()`（约第 594 行）

**stats 区域改造**：
- 将 `<br>` 分隔的属性改为每个属性一个 `<div>`，放入 `<div class="stats-box">`
- 每行一个属性：`<div><span class="label">总评分:</span> <span>975.0K</span></div>`
- `.stats-box` 的 3 列 grid 自动排列

```js
// 旧: statsHtml = `<b>总评分: ...</b><br>装备评分: ...<br>攻击力: ...<br>...`

// 新: statsHtml = `<div class="stats-box">`
//   + `<div><span class="label">总评分:</span> <span style="color:var(--primary)">${...}</span></div>`
//   + `<div><span class="label">装备评分:</span> ${...}</div>`
//   + `...` (攻击力/防御力/暴击/冷却/共鸣 各一个 <div>)
//   + `</div>`
```

**宝珠区域改造**：
```js
// 旧: 内联 `border-top:1px dashed #444` + 每个孔位 div
// 新: 
statsHtml += `<div class="gem-system">`;
statsHtml += `<div style="font-size:12px;color:#94a3b8;">宝珠孔位 (同类全身最多生效${MAX_SAME_ORB}个)</div>`;

for (let i = 0; i < orbLen; i++) {
  statsHtml += `<div class="gem-slot-row">`;
  statsHtml += `<span>孔位${i+1}: ...</span>`;  // 宝珠信息 + 镶嵌按钮
  // 如有宝珠: 再 append 卸下按钮
  statsHtml += `</div>`;
}
statsHtml += `</div>`;
```

**按钮区域**：
```js
// 旧: 直接 innerHTML 按钮
// 新: 包裹在 `<div class="action-buttons" style="display:flex;gap:10px;">` 中
// 按钮加 class: 锁定🔒用 `btn btn-gold`，防换📌用 `btn btn-red`
```

### `_renderModalFoot()`（约第 500 行）

- 底部按钮统一使用 `.btn` / `.btn-red` / `.btn-gold` 风格
- 匹配 `.terminal-footer` 的 flex + gap 布局

### 不需要改动的方法
- `embedOrb()`、`removeOrb()` — 只更新 DOM 后调用 `openGearDetail()` 刷新
- `toggleLock()`、`togglePin()` — 同上
- `enterBatchMode()`、`exitBatchMode()`、`batchSelectAll()` 等 — 逻辑不变
- `cycleSortMode()`、`openBackpack()`、`openSlotView()` — 逻辑不变
- `_setupVirtualScroll()` / `_teardownVirtualScroll()` — 引擎完全不动
